Tell Git Who You Are

Configure author name
git config --global user.name "<username>"
Configure author email
git config --global user.email <email address>

Getting and Creating Projects

Initialize a local repository
git init
Clone repository over SSH
git clone ssh://git@github.com/<username>/<repository-name>.git

Basic Snapshotting

Check status
git status
Add a file to staging
git add <file-name.txt>
Add all files to staging
git add -A or git add .
Commit changes
git commit -m "<commit message>"
Remove file or folder
git rm -r <file-name.txt>

Inspection and Comparison

View changes
git log
View changes (detailed)
git log --summary
One-line view
git log --oneline or git log --pretty=oneline or git log --pretty=short

Undo to Previous File/Commit

List commits with id and message
git log --oneline
Checkout previous commit
git checkout <commit id>
Revert one commit
git revert <commit id>
Reset hard to commit
git reset --hard <commit id>
Stop tracking file or folder
git rm --cached <file/folder>
Restore a file
git checkout <file/to/restore>

Branching and Merging

List branches
git branch
List all branches (local and remote)
git branch -a
Create branch
git branch <branch name>
Create and switch to branch
git checkout -b <branch name>
Track remote branch locally
git checkout -b <branch name> origin/<branch name>
Rename local branch
git branch -m <old branch name> <new branch name>
Switch branch
git checkout <branch name>
Switch to last checked-out branch
git checkout -
Discard changes in file
git checkout -- <file-name.txt>
Delete local branch
git branch -d <branch name>
Delete remote branch
git push origin --delete <branch name>
Preview diff before merge
git diff <source branch> <target branch>
Merge branch into active branch
git merge <branch name>
Merge source branch into target branch
git merge <source branch> <target branch>
Stash local changes
git stash
Clear stash entries
git stash clear

Sharing and Updating Projects

Push branch to remote
git push origin <branch name>
Push and remember branch
git push -u origin <branch name>
Push to remembered branch
git push
Push all branches
git push --all
Force push
git push -f
Delete remote branch
git push origin --delete <branch name>
Update local repository
git pull
Pull specific branch
git pull origin <branch name>
Add remote origin
git remote add origin ssh://git@github.com/<username>/<repository-name>.git
Set remote URL to SSH
git remote set-url origin ssh://git@github.com/<username>/<repository-name>.git

In-Depth Feature Workflow

This is a full production-friendly workflow from sync to PR, with copyable command blocks.

1) Sync Main Before Starting

git checkout main
git pull origin main

2) Create and Start Feature Branch

git checkout -b feature/<short-name>

3) Commit in Small Units

git status
git add -A
git commit -m "feat: implement <small change>"

4) Publish Branch and Open PR

git push -u origin feature/<short-name>

5) Keep Feature Branch Up To Date

git checkout main
git pull origin main
git checkout feature/<short-name>
git merge main

6) After PR Merge, Clean Up

git checkout main
git pull origin main
git branch -d feature/<short-name>
git push origin --delete feature/<short-name>

Merge Conflict Playbook (In-Depth)

Check files with conflicts
git status
List unresolved conflict files only
git diff --name-only --diff-filter=U
Inspect conflict markers in files
git diff
See commits related to merge conflict
git log --merge
Compact conflict-related commit history
git log --merge --oneline
Accept current branch version for one file
git checkout --ours <file>
Accept incoming branch version for one file
git checkout --theirs <file>
Open visual merge tool if configured
git mergetool
Mark resolved files
git add <file>
Finish merge after resolution
git commit -m "resolve: merge conflict in <area>"
Abort merge if needed
git merge --abort
Abort rebase if needed
git rebase --abort
Skip current patch during rebase conflict
git rebase --skip
Continue rebase after resolving files
git rebase --continue

Fast Conflict Resolution Flow

git status
git diff
git add <file1> <file2>
git commit -m "resolve: merge conflicts"

Rebase Conflict Resolution Flow

git status
git diff --name-only --diff-filter=U
git add <file1> <file2>
git rebase --continue
